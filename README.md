# LAMP SERVER PROJECT

## Overview
A LAMP server deployed using RHEL 10.2

## Technologies

-Linux (RHEL 10.2)
-Apache HTTP Server
-MariaDB
-PHP
-PHP-FPM

## Features
-Apache Web Server configuration
-MariaDB database installation
-PHP-FPM integration
-Firewall Configuration
-Client-Server connectivity
